# References

The following sources were instrumental in the development of the Lab Lens prototype.

### Primary Dataset
1. **ChemEq25**: Chemistry Lab Image Dataset Covering 25 Apparatus Categories.  
   *Source*: Figshare.  
   *License*: CC BY 4.0.  
   *URL*: [https://figshare.com/articles/dataset/_b_Chemistry_Lab_Image_Dataset_Covering_25_Apparatus_Categories_b_/29110433](https://figshare.com/articles/dataset/_b_Chemistry_Lab_Image_Dataset_Covering_25_Apparatus_Categories_b_/29110433)

### Core Technologies
2. **Ultralytics YOLOv8**: Real-time object detection architecture used for bounding box extraction.  
   *Documentation*: [https://docs.ultralytics.com](https://docs.ultralytics.com)
3. **OpenCV**: Open Source Computer Vision Library utilized for image decoding, Laplacian blur variance calculation, and pixel preprocessing.  
   *Documentation*: [https://opencv.org/](https://opencv.org/)
4. **NumPy**: The fundamental package for scientific computing with Python, used extensively for Cartesian bounding box mathematics and intersection-over-union (IoU) mapping.  
   *Documentation*: [https://numpy.org/](https://numpy.org/)

### Demonstration Media
5. **Wikimedia Commons**: Source for the 16 authentic, CC-licensed real-world laboratory photographs utilized in the E2E spatial compliance pipeline demonstration.  
   *(Specific attribution metadata and source URLs for each individual photograph are meticulously tracked inside `Dataset/SpatialComplianceReal/metadata/ATTRIBUTION.md`)*.
